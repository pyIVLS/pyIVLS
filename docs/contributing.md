# Style guide
Formatting enforced with [Ruff Formatter](https://docs.astral.sh/ruff/formatter/) with standard settings (Except for max_line_length of 120). New code should strive to use the naming convention defined in [PEP 8](https://peps.python.org/pep-0008/#naming-conventions).

# Tests
The standard components have unit tests for them, so if writing new code that does not use them, it would be good to add some basic tests too
